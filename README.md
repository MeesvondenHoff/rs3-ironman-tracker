# RS3 Ironman: Ons Pap

Tracker- en planningsapp plus research voor het RuneScape 3 solo-Ironmanaccount "Ons Pap". Alles gaat over RS3, nooit over Old School RuneScape.

- `CLAUDE.md`: alle projectkennis, werkregels, het profiel van de speler en de uitleg van Ironman Mode. Claude Code laadt dit bestand vanzelf; begin hier.
- `app/`: de tracker (Vite + React + TypeScript). Starten: `npm install --prefix app` en `npm run dev --prefix app`, daarna http://localhost:5173. Zie `app/README.md`.
- `research/`: de route (`Route Ons Pap.md`), de afweging van guides, game-updates, site-reviews, snapshots en de scripts die `route.json` bouwen en valideren.

Verder werken op een andere computer: kloon de repo, open de map in Claude Code en de context staat klaar. Vinkjes en notities van de app staan in de browser; neem die mee via de back-up in het Logboek.
